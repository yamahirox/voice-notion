PC で「話し始める」が動かない・無反応のとき

Google Chrome または Microsoft Edge（PC にインストールしたもの）で http://127.0.0.1:8765/idea-city を開いてください。Cursor / VS Code の内蔵プレビュー（Simple Browser）では、Web Speech API が無効でマイクが動かないことがあります。

「話し始める」のあとダイアログが出ないとき: すでにマイク許可済みなら出ません（そのまま「聞いています…」）。一方、一度ブロックするとダイアログは出ないまま失敗します。アドレスバー左の鍵／i → マイクを許可に直してください。

Windows の設定 → プライバシーとセキュリティ → マイクでマイクアクセスがオンか確認してください。

アドレスバーの鍵・︙から、このサイトのマイクが「許可」になっているか確認してください。

この開き方（例: http://192.168…）のスマホ：入力欄をタップ → キーボードのマイクで話す → 改行で区切ってからNotion に一括登録。PC の 127.0.0.1 なら「話し始める」が使えます。

サーバ: http://127.0.0.1:8765/idea-city ・ 音声1件転記（別タブ・このページはそのまま） ・ Notion ソース Q&A

スマホに「ボタン」を用意する（ホーム画面に追加）
  1. PC とスマホを同じ Wi‑Fi にします。
  2. PC で ipconfig（PowerShell/CMD）し、IPv4 アドレス（例: 192.168.x.x）を控えます。
  3. PC で次を実行してサーバを立ち上げます:
    python -m uvicorn sandbox.app.voice_server:app --host 0.0.0.0 --port 8765
  4. スマホのブラウザで http://（控えたIP）:8765 を開きます。
  5. iPhone（Safari）: 共有 → ホーム画面に追加。Android（Chrome）: メニュー → ホーム画面に追加 / ショートカット。
インターネットの URL（クラウド）で外からいつでも使う
  1. Railway・Render・Fly.io などに、このフォルダの Dockerfile でデプロイし常時起動させます。
  2. ホストの環境変数に NOTION_API_KEY と NOTION_DATABASE_ID を必ず設定します。
  3. 悪用防止のため VOICE_SHARED_SECRET（20文字以上のランダム）を強く推奨します。
  4. 発行された https://… をスマホで開き、下に同じパスワードを入れて保存してください（端末のブラウザにだけ残ります）。
ご家庭の Wi‑Fi の http://192.168… では、ブラウザの「話し始める」は多くのスマホで使えません（Chrome の仕様）。入力欄をタップし、Gboard のマイクで話してください。PC の 127.0.0.1 では「話し始める」が使えます。
